# Machine-Test Interviewer Review

Act as a skeptical senior .NET interviewer reviewing this repository.

Read all project documentation and source code.

Ask what you would challenge the candidate on:
- architecture choices
- ownership/data modelling
- leave overlap semantics
- concurrency
- authentication and authorization
- EF Core choices
- transaction isolation
- error handling
- test strategy
- scalability
- why certain patterns were NOT used

Do not modify code.

Produce:
1. 15 likely interview questions
2. What evidence in the code would support a good answer
3. Red flags that would weaken the answer
4. Three realistic change requests that could be given during the interview
